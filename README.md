# Quiz

Projeto de Quiz desenvolvido com React, TypeScript e Vite.

A aplicação apresenta perguntas ao usuário, permite selecionar respostas, acompanha o progresso e exibe o resultado ao final do quiz.

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- Vite
- CSS
- JSON
- Git e GitHub

## 📚 Funcionalidades

- Exibição de perguntas e alternativas
- Seleção de respostas
- Barra de progresso
- Contagem das respostas
- Resultado final do quiz
- Questões armazenadas em arquivo JSON
- Interface responsiva
